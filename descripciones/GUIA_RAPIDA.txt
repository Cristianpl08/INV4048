📋 COLUMNAS DEL CSV RESULTANTE
═══════════════════════════════════════════════════════════════════════

• post_id              → ID del post
• title                → Título
• link                 → URL
• pub_date             → Fecha de publicación
• creator              → Autor
• content              → Contenido (primeros 500 caracteres)
• excerpt              → Extracto
• post_date            → Fecha del post
• post_date_gmt        → Fecha GMT
• post_modified        → Última modificación
• post_modified_gmt    → Última modificación GMT
• status               → Estado (publish, draft, etc.)
• post_type            → Tipo (post, page, tribe_events, etc.)
• post_name            → Slug
• categories           → Categorías (separadas por ;)
• event_start_date     → Inicio del evento
• event_end_date       → Fin del evento
• event_timezone       → Zona horaria
• event_url            → URL del evento


📋 SOLUCIÓN DE PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════

❌ "Python no está instalado"
   → Instala Python desde: https://www.python.org/downloads/
   → Asegúrate de marcar "Add Python to PATH" durante la instalación

❌ "No se encuentra el archivo"
   → Verifica que el archivo XML está en la misma carpeta
   → O especifica la ruta completa:
     python convertir_simple.py "C:\Users\tuusuario\Desktop\archivo.xml"

❌ "El archivo XML está mal formado"
   → Verifica que el archivo se descargó completamente
   → Abre el XML en un navegador para validarlo

❌ "No tienes permisos para escribir"
   → Cierra el archivo CSV si está abierto en Excel
   → Ejecuta como administrador
   → Guarda en otra ubicación

❌ "Caracteres extraños en Excel"
   → En Excel: Datos → Desde texto/CSV
   → Selecciona "UTF-8" como origen del archivo
   → O usa Google Sheets / LibreOffice Calc


📋 CONSEJOS Y TRUCOS
═══════════════════════════════════════════════════════════════════════

💡 Para abrir CSV en Excel correctamente:
   1. Abre Excel
   2. Datos → Obtener datos → Desde archivo → Desde texto/CSV
   3. Selecciona tu archivo CSV
   4. Asegúrate que "Origen del archivo" sea: 65001: Unicode (UTF-8)
   5. Haz clic en Cargar

💡 Para procesar múltiples archivos:
   Crea un script batch (.bat) con:
   
   @echo off
   for %%f in (*.xml) do (
       python convertir_simple.py "%%f"
   )
   pause

💡 Para filtrar solo eventos:
   Abre xml_to_csv.py y modifica el código agregando:
   
   if post_type == "tribe_events":
       writer.writerow({...})

💡 Para incluir TODO el contenido (sin límite de 500 caracteres):
   En xml_to_csv.py, cambia:
   'content': content[:500] + '...' if len(content) > 500 else content
   Por:
   'content': content
