# Video Prosody and Speaker Diarization Pipeline

This repository contains the video-analysis contribution developed for a research project on universal access to prosodic information. It provides a reproducible workflow for extracting audio from a video, identifying speakers, locating silent intervals, and using scene changes to refine those intervals.

## What the pipeline does

1. Extracts a WAV audio track from a local video.
2. Sends the audio to pyannoteAI for speaker diarization.
3. Reconstructs one audio track per detected speaker.
4. Detects silence between speech segments.
5. Merges nearby silent segments when appropriate.
6. Uses content-based scene detection to split silent intervals that contain visual scene changes.
7. Saves the intermediate and final annotations as JSON files.

## Repository layout

```text
.
├── data/                 # Sample diarization and silence-analysis annotations
├── notebooks/            # End-to-end exploratory pipeline notebook
├── src/                  # Python implementation and reusable helper functions
├── .env.example          # Template for local pyannoteAI credentials
├── requirements.txt      # Python dependencies
└── README.md             # Project documentation
```

### `data/`

Contains small JSON outputs produced by the pipeline:

- `diarization.json` stores time intervals labelled with speaker identifiers.
- `silent_segments_joined.json` stores nearby silent intervals after joining logic.
- `silent_segments_with_scenes.json` stores the final silent intervals after scene-based refinement.

### `notebooks/`

Contains `test.ipynb`, the end-to-end notebook. It documents the complete experimental workflow, including optional Google Drive upload, audio extraction, diarization, speaker-track generation, silence analysis, and scene detection.

### `src/`

Contains `Testprueba.py`, a compact Python implementation of the local video/audio workflow. It defines functions for audio extraction, speaker diarization, per-speaker audio reconstruction, silence detection, joining close intervals, and scene-aware interval splitting.

## Setup

Python 3.10 or newer is recommended. FFmpeg must also be installed and available on your `PATH` for MoviePy and pydub.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Create a local `.env` file from `.env.example`, add a valid pyannoteAI token, and export it before running the script:

```bash
export PYANNOTE_API_TOKEN="your_token_here"
python src/Testprueba.py
```

## Data and privacy

Raw videos, extracted WAV files, and per-speaker audio files are intentionally not versioned. They may be large, contain personal data, and can exceed GitHub's file-size limits. Place those files locally when reproducing the workflow; Git ignores common video and audio formats by default.

The JSON annotations in `data/` are included as lightweight examples of the expected outputs.

## Notes

- Speaker labels are generated by the diarization service and are not real identities.
- Scene detection uses PySceneDetect's `ContentDetector` with a threshold of `27.0` in the provided code.
- This repository contains the implementation contribution, not the research paper or its source media.
